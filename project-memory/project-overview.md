# Project Overview

Exam Platform is a production-oriented Next.js App Router application for online exams.

## Purpose

- Students take exams and view their own progress.
- Teachers create and manage questions/exams for their own students.
- Admins can see and manage everything.

## Stack

- Next.js 16.2.6 App Router
- React 19.2.4
- TypeScript
- Tailwind CSS 4
- NextAuth.js 4
- Supabase Auth and PostgreSQL
- Vercel deployment target
